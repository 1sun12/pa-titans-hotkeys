# RTS hotkeys

Versioned keybinds for two RTS games on this host, kept apart so each can change on its own.

- [`PA/`](PA/README.md): Planetary Annihilation: Titans keybinds and Hotbuild2 layout.
- [`BAR/`](BAR/README.md): Beyond All Reason keymap, plus the game's full keybind and build-grid reference.
