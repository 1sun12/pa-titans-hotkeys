# BAR build grid

Generated by `render.py` from `game_defaults.json`. Do not edit by hand.

The grid menu puts every build option on a 3x4 block of keys:

```
Q W E R   row 3
A S D F   row 2
Z X C V   row 1
```

Factories show their units straight on the grid; *p2* is the second page (`B` flips pages).
Builders first pick a category (Z Economy, X Combat, C Utility, V Build), then a grid key: a T1 bot constructor builds a metal extractor with Z then Z.
