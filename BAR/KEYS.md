# BAR hotkeys

Generated by `render.py` from `uikeys.txt`. Do not edit by hand.

Game build: Beyond All Reason test-31958-7ffdbab. Active profile: **Grid**, compared against the shipped **Grid** profile. *changed* marks actions whose keys differ; empty means unbound.

Letter keys are scancodes (physical position, same on any layout). `Any+` fires whatever modifiers are held. `a,b` is a chain: press a then b. Space is the Meta key.
